# 验证与模型晋级方案

首版使用可解释的影子基线，只为建立干净样本链，不宣称模型已经晋级。评分综合D日以前的5/20日趋势、波动、尾部损失、最大回撤、成交额、三源名次共识与有限的上游先验；上游三个来源高度相关，因此先验总权重受限，绝不相乘。

正式学习模型只有满足以下条件才允许替换基线：

- 按D日整组的滚动前推验证，禁止随机打乱；
- 训练样本的真实 `label_end_date` 早于验证期，延迟退出样本按实际结束日清除重叠；
- 至少180笔成熟交集交易，且固定每个名次至少60笔；
- 最后126个交易日锁箱，不能参与调参；
- 与三表Borda名次、单源排序、交集等权和始终不交易比较；
- 报告费用后收益、最大回撤、CVaR10%、成交率、延迟退出率、数据覆盖率；
- 基础成本、双倍成本、涨停同价全部不成交三组压力测试均通过；
- 任何数据覆盖率不足、未来信息泄漏或静默删除未成熟样本都直接判失败。

未来模型拆成四部分：`P_fill_0925`、条件净收益分布、正收益概率、延迟退出概率。最终排名优化真实可执行的样本外风险效用，不优化展示用AUC，也允许独立 `NO_TRADE`。
