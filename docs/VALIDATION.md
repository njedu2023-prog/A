# 验证与模型晋级方案

## 当前生产状态

正式 V2 已运行，但在真实成熟样本达到门槛以前，生产冠军固定为可解释的 `transparent_shadow_champion_v2`。它输出与学习模型完全相同的预测契约，便于从第一天开始积累可比较的冻结预测；这些启发式输出不冒充已经校准的统计概率。

学习型挑战者可以被训练和离线评估，但训练程序绝不自行晋级，也不会自动改写冠军。模型注册表明确记录当前冠军、挑战者状态、制品路径、SHA-256和样本准备度。

## 标签口径

训练数据由 `build_training_dataset()` 从冻结状态纯函数生成：

- 成交：合法T日未复权开盘价存在时固定为1；旧版未成交状态兼容为0；
- 净收益：只来自按开盘价计入且最终完全退出的费用后收益；
- 策略收益：未成交为现金0，完成退出为真实费用后收益；
- 退出延迟：按实际完成退出相对计划T+1的交易日数；
- 晋级：T日无复权收盘验证，和买入是否成交相互独立；
- `label_end_date`：取该行所有已知目标的最晚真实结束日。

未完成记录保留在数据集中但标签为 `null`，不能静默删除、填0或用于训练期的中位数和标准化统计。成熟样本必须是 `CLOSED` 或历史兼容的 `BUY_UNFILLED`。

## 特征与学习头

学习矩阵只取固定白名单中的有限数值特征。缺失值的中位数、均值和尺度只在每个训练折内拟合，再应用到验证折，禁止全样本预处理造成泄漏。

挑战者包含：

- L2 Logistic：退出延迟、T日晋级；成交头仅作旧制品兼容；
- Huber线性：开盘成交后的费用后净收益均值；
- Pinball线性：净收益第10/50/90分位；
- 正值链接回归：预期延迟交易日。

独立分位回归发生交叉时，推理层统一投影为 `q10 ≤ q50 ≤ q90`。晋级头是辅助任务，不直接替代费用后收益排序。

## 时序验证

所有拆分按完整D日候选组进行，禁止随机打乱或把同一天拆进训练和验证两侧：

1. 先把最后126个成熟D日划为锁箱，开发阶段不可读取；
2. 对其余数据做扩展窗口前推验证；
3. 每个验证窗口前设置2个交易日隔离；
4. 只有 `label_end_date` 严格早于隔离截止日的样本可进入训练；
5. 延迟退出以实际结束日清除重叠，不能按计划T+1提前泄漏；
6. 每折的填补、标准化和模型头只在该折训练集拟合。

默认开发窗口至少60个D日、验证窗口20个D日。日历隔离按交易日而非自然日计算。

## 最低准入门槛

挑战者进入正式外部验证至少需要：

- 180笔成熟候选；
- 固定第1、第2、第3名各不少于60笔成熟样本；
- 至少126个成熟D日可形成最终锁箱；
- 退出延迟与晋级分类头具备足够的正负两类样本；
- 条件收益与延迟日头各具备足够的已知目标。

任一项不足时状态为 `INSUFFICIENT_DATA/NOT_ELIGIBLE`，透明冠军继续运行。满足样本门槛只表示可以开始验证，不表示模型自动晋级。

## 必须报告的证据

前推样本外报告至少包括：

- 延迟和晋级概率的 Brier、LogLoss、ECE与样本数；
- 费用后策略日收益均值、最大回撤、CVaR10%；
- 开盘价覆盖率、退出延迟率、特征覆盖率和分位覆盖表现；
- 与三表Borda、单源名次、全部交集等权、始终不交易的基准比较；
- 基础成本、双倍成本、涨停同价全部不成交三组压力测试；
- 各折训练期、验证期、隔离截止日、训练截止日和锁箱范围；
- 模型、特征顺序、训练数据及来源证据的确定性指纹。

只有前推、校准、费用后收益、回撤/CVaR、压力测试和锁箱均通过，且产生独立确认的晋级决定后，才可签发 `promotion_certificate_v1`。证书必须绑定模型内容、评价数据和必需检查报告的指纹；旧式 `validation_passed=true` 没有激活能力。运行时仍会再次校验制品路径、文件SHA-256、模型内容指纹、证书一致性、特征版本和 `trained_through < D`；任一项失败都自动回退透明冠军。

## 生产排名与门槛

最终排名只按真实可执行风险效用排序：

```text
U = E[R_net]
    − λ_tail × ES10
    − λ_delay × P_delay × E[delay_days]
    − λ_uncertainty × uncertainty
```

`P_fill` 在开盘成交口径下固定为1，不参与效用或门槛。展示用晋级概率不直接加入效用。策略门槛允许 `NO_TRADE`；但为了避免幸存者偏差，三表实际交集中的每支股票仍冻结预测、订单规格并进入影子账本。若同日任一候选的D时点市场特征不完整，则整个候选组统一使用Borda排序且全部关闭策略门槛，避免一日内混合模型排名与降级排名。
